# 小红书工作台

本地运行的小红书内容工作台。**前端开源，内核闭源。**

## 这是什么

输入一个内容方向，批量生成笔记草稿 → 逐条审核 → 发布。带幂等账本，
同一条内容不会被发两次。支持虚拟商品卡密发货。

## 仓库结构

```
.
├── web/                 前端（MIT 开源）
├── skills_builtin/      写作技能包（MIT 开源）
├── launcher.py          启动器（MIT 开源）
├── releases/            内核放这里（不提交到 git）
├── SHA256SUMS.txt       内核校验值
├── LICENSE              开源部分：MIT
├── LICENSE-CORE         内核部分：闭源
└── NOTICE.md            第三方组件与致谢
```

## 为什么内核闭源

前端跑在浏览器里，本来就不可能藏住，索性完全开源，方便你改样式、加页面。
内核含发布调度、幂等账本、适配器、技能注入等逻辑，这部分是作者的主要工作，
以编译产物分发。

**这不是「开源软件」**，是「开源前端 + 闭源内核」的混合分发。
